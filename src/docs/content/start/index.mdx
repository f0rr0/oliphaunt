Oliphaunt is PostgreSQL embedded in your application. Use PostgreSQL queries, types, and extensions through an SDK for your language, without setting up a separate database service.

## Choose your SDK

<SdkChooser />

Start with the native SDK for your app's platform. For a browser app, use **WASIX TypeScript**. WASIX runs PostgreSQL as WebAssembly and also has a Rust binding.

Each quickstart includes installation, a complete query example, and persistent storage setup. Compare [runtime support](/docs/reference/capabilities) if you need process isolation, an ORM, or browser storage.

## After your first query

- **Build application features.** Your SDK's guide covers parameters, transactions, backups, and errors.
- **Understand storage.** [Embedded PostgreSQL](/docs/learn/embedded-postgres) explains database lifetime and recovery.
- **Add PostgreSQL extensions.** [Choose an extension](/docs/reference/extensions), then follow your SDK's setup.
- **Bring an existing app.** Read [Moving from SQLite](/docs/learn/sqlite-upgrade) or [Use with Tauri](/docs/learn/tauri).
