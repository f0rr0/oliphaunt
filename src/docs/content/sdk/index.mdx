## PostgreSQL as WebAssembly

The WASIX SDKs run PostgreSQL compiled to **WebAssembly**. [WASIX](https://www.wasix.org/docs/#what-is-wasix) supplies the system interfaces, such as files and clocks, that WebAssembly programs need. Oliphaunt uses these interfaces to host PostgreSQL inside your application.

Use WASIX TypeScript in browsers, Node.js, Bun, Deno, and Electron. Use WASIX Rust in Rust desktop applications, including Tauri. Your application uses its usual language and build tools; the SDK runs the WebAssembly database. A native desktop application can use either PostgreSQL runtime.

## Native PostgreSQL

Swift, Kotlin, and React Native embed native PostgreSQL in iOS and Android apps. Swift also supports macOS. These SDKs provide async queries, app-private persistent storage, and platform integration for extensions and process isolation.

Native Rust and native TypeScript support desktop hosts, including Tauri and Node.js, Bun, Deno, and Electron. They offer direct embedding, a broker process, and a local PostgreSQL server with independent client sessions. The WASIX SDKs have their own execution and endpoint choices; see [Choose how PostgreSQL runs](/docs/learn/native-runtime).

Select the runtime through its package. See [SDKs and platforms](/docs/reference/sdk-products) for package names and [runtime support](/docs/reference/capabilities) for host requirements, storage, tools, and concurrency differences.
