## Native or WASIX?

Native SDKs run the native PostgreSQL runtime. Use them for mobile apps and desktop applications that can ship native libraries. Rust and desktop TypeScript also support a separate database process and a local PostgreSQL server.

WASIX SDKs run PostgreSQL compiled to WebAssembly. Use WASIX TypeScript in browsers, or either WASIX binding when you want that runtime in a desktop host. Select WASIX explicitly; the native packages do not switch to it automatically.

See [SDKs and platforms](/docs/reference/sdk-products) for package names and [runtime support](/docs/reference/capabilities) for storage, tools, and concurrency differences.
