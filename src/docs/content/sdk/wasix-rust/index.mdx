---
title: WASIX Rust SDK
description: Run WebAssembly PostgreSQL in Rust desktop and Tauri apps, with synchronous or async APIs.
---

Use `oliphaunt-wasix` to run [WebAssembly PostgreSQL](/docs/sdk#postgresql-as-webassembly) in Rust desktop applications, including Tauri. Your Rust application builds as a normal native executable; the SDK hosts the WebAssembly database. The [native Rust SDK](/docs/sdk/rust) offers the other PostgreSQL runtime choice.

## Install

```toml
[dependencies]
oliphaunt-wasix = "{{release:oliphaunt-wasix-rust}}"
```

Use Rust 1.93 or later. The package resolves matching host assets for macOS ARM64, Linux GNU x64/ARM64, and Windows MSVC x64. See [host support](/docs/reference/capabilities#supported-webassembly-hosts).

## Run your first query

Create a complete `src/main.rs`:

<!-- oliphaunt-snippet: oliphaunt-wasix-rust -->

```rust
use oliphaunt_wasix::Oliphaunt;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let mut db = Oliphaunt::open()?;
    let result = db.sql("SELECT $1::int4 AS answer").bind(42_i32).query()?;
    let answer: i32 = result.rows()[0].try_get("answer")?;
    println!("{answer}"); // 42
    db.close()?;
    Ok(())
}
```

Run with `cargo run`. The default database uses a memory filesystem and is discarded on close.

## Keep data between runs

```rust
use oliphaunt_wasix::{DatabaseStorage, Oliphaunt};

let mut db = Oliphaunt::builder()
    .storage(DatabaseStorage::Directory("./data/notes".into()))
    .open()?;
```

Only one live owner can open a persistent root. Reopen the same path to access saved data.

## Choose synchronous or async ownership

The synchronous `Oliphaunt` is **not `Send` or `Sync`**. Create, use, close, and drop it on the same OS thread. Use `AsyncOliphaunt` for a cloneable `Send + Sync` handle:

```rust
use oliphaunt_wasix::{AsyncOliphaunt, DatabaseStorage};

let db = AsyncOliphaunt::builder()
    .storage(DatabaseStorage::Directory("./data/notes".into()))
    .open()
    .await?;
let result = db.query("SELECT 42::int4 AS answer").await?;
db.close().await?;
```

This fragment runs inside an async function. Async clones share one owner and session. For a native desktop UI, keep this handle in application state; see [Use with Tauri](/docs/learn/tauri#webassembly-postgresql). Continue with the [WASIX Rust guide](/docs/sdk/wasix-rust/guide), [runtime behavior](/docs/sdk/wasix-rust/runtime), or [API reference](/docs/sdk/wasix-rust/api-reference).
