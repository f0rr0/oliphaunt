title: SDKs and platforms

Your application's platform and the PostgreSQL runtime are separate choices. Rust desktop and Tauri apps can use either runtime, as can Node.js, Bun, Deno, and Electron. Browsers use [WebAssembly PostgreSQL](/docs/sdk#postgresql-as-webassembly); the mobile SDKs use native PostgreSQL.

| SDK | Package | Application targets | PostgreSQL runtime | Default storage |
| --- | --- | --- | --- | --- |
| [WASIX TypeScript](/docs/sdk/wasix-typescript) | `@oliphaunt/wasix-ts` | Browser, Node.js, Bun, Deno, Electron | WebAssembly | Memory filesystem |
| [Swift](/docs/sdk/swift) | `Oliphaunt` | iOS, macOS | Native | Temporary directory |
| [Kotlin](/docs/sdk/kotlin) | `dev.oliphaunt:oliphaunt-android` | Android | Native | Temporary directory |
| [React Native](/docs/sdk/react-native) | `@oliphaunt/react-native` | iOS, Android; Expo native builds | Native | Temporary directory |
| [WASIX Rust](/docs/sdk/wasix-rust) | `oliphaunt-wasix` | Rust desktop, Tauri | WebAssembly | Memory filesystem |
| [Native Rust](/docs/sdk/rust) | `oliphaunt` | Rust desktop, Tauri | Native | Temporary directory |
| [Native TypeScript](/docs/sdk/typescript) | `@oliphaunt/ts` | Node.js, Bun, Deno, Electron | Native | Temporary directory |
| [C ABI](/docs/sdk/c-abi) | `liboliphaunt` | Custom native bindings | Native | Caller-prepared managed root |

## Build for your application

Use Swift for SwiftUI and iOS/macOS integration, Kotlin for Android coroutines, or React Native for TypeScript across iOS and Android. React Native uses the Swift and Kotlin integrations and requires a native app build. See [mobile lifecycle](/docs/learn/mobile-stability) for persistent storage and process isolation.

WASIX TypeScript provides the same query API across its browser and Node.js/Bun/Deno/Electron hosts, with storage adapters and execution placement selected for each host. Those JavaScript hosts load a platform-specific native addon to execute WebAssembly PostgreSQL. Check [supported hosts](/docs/reference/capabilities#supported-webassembly-hosts) before choosing a deployment target.

In Tauri, either Rust SDK keeps database work in the Rust backend and exposes application commands to the webview. See [both Tauri integrations](/docs/learn/tauri). Native Rust and native TypeScript also provide server mode for independent driver sessions.
