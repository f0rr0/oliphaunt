Choose the package for your application's language and runtime. Native and WASIX packages are separate choices.

| SDK | Package | Application targets | Default storage |
| --- | --- | --- | --- |
| [Rust](/docs/sdk/rust) | `oliphaunt` | Native desktop, Tauri | Temporary directory |
| [Swift](/docs/sdk/swift) | `Oliphaunt` | iOS, macOS | Temporary directory |
| [Kotlin](/docs/sdk/kotlin) | `dev.oliphaunt:oliphaunt-android` | Android | Temporary directory |
| [React Native](/docs/sdk/react-native) | `@oliphaunt/react-native` | iOS, Android | Temporary directory |
| [TypeScript](/docs/sdk/typescript) | `@oliphaunt/ts` | Node.js, Bun, Deno, Electron | Temporary directory |
| [WASIX Rust](/docs/sdk/wasix-rust) | `oliphaunt-wasix` | Rust hosts | Memory filesystem |
| [WASIX TypeScript](/docs/sdk/wasix-typescript) | `@oliphaunt/wasix-ts` | Browser, Node.js, Bun, Deno, Electron | Memory filesystem |
| [C ABI](/docs/sdk/c-abi) | `liboliphaunt` | Custom native bindings | Caller-prepared managed root |

## Runtime differences

React Native uses the Swift and Kotlin native integrations. A Tauri app normally keeps its database in Rust and exposes application commands to the webview.

WASIX TypeScript uses a browser WebAssembly host in browsers and its own native host integration on desktop. Both run the WASIX PostgreSQL runtime. This does not select or import the native `@oliphaunt/ts` SDK.

Use [Runtime support](/docs/reference/capabilities) to compare persistent storage, local endpoints, and optional tools. Each SDK quickstart describes its platform setup.
