# Runtime Support

Choose a product by its documented runtime contract. Support is intentionally a
static product fact, not a capability-reporting API that every application must
query after open.

## Products

| SDK | Package | Hosts |
| --- | --- | --- |
| C ABI | `liboliphaunt` | Native direct binding boundary |
| Rust | `oliphaunt` | Native direct, broker, server |
| Swift | `Oliphaunt` | Native direct on iOS and macOS |
| Kotlin | `dev.oliphaunt:oliphaunt-android` | Native direct on Android |
| React Native | `@oliphaunt/react-native` | Swift/Kotlin direct adapters |
| TypeScript | `@oliphaunt/ts` | Native direct, broker, server on supported desktop runtimes |
| Rust WASIX | `oliphaunt-wasix` | WASIX direct and local server |
| WASIX TypeScript | `@oliphaunt/wasix-ts` | Browser, Node, Bun, and Deno direct or Worker execution |

## Feature support

| Feature | Native SDK family | Rust WASIX | WASIX TypeScript |
| --- | --- | --- | --- |
| Default storage | SDK-owned temporary directory | Memory filesystem | Memory filesystem |
| Persistent storage | Managed directory; React Native also resolves application-data names | Managed directory | IndexedDB/OPFS in browsers; managed directory on Node, Bun, Deno |
| Typed query and command helpers | Yes | Yes | Yes |
| Raw PostgreSQL protocol | Yes where the language boundary carries bytes | Yes, buffered | Yes, buffered |
| Callback transactions | Yes | Yes | Yes |
| Checkpoint | Yes | Yes | Yes, followed by provider publication |
| Cancellation | Yes | No public direct-query cancellation | No public direct-query cancellation |
| Dedicated COPY streaming | No | No | No |
| Exact extension selection | SQL names | Typed Cargo selections | Selectively imported WASIX descriptors |
| Physical backup/restore | Backup in direct/broker and mobile direct; static restore to new/empty storage | Yes | Backup from memory or persistent open sessions; static restore to a new or empty persistent provider |
| Listening server | Rust and desktop TypeScript | Yes | No |
| `pg_dump` / `psql` | Separate desktop products; desktop TypeScript has no SDK tools API or dependency | Optional `tools` feature | No |
| Independent client sessions | Native server only | No; the local endpoint accepts one connected client at a time | No |

The low-level C ABI retains a callback raw-protocol boundary for native binding
adapters. App-facing SDK raw and typed calls remain buffered until a deliberate
COPY stream API exists.

## Selection guidance

Choose a native SDK when the application ships native runtime artifacts and
wants direct, helper-process, or server integration. Choose Rust WASIX when a
Rust host needs the portable runtime, optional local endpoint, or packaged
tools. Choose WASIX TypeScript for portable browser or Node/Bun/Deno embedding
with memory or explicit persistent providers.

Native and WASIX packages never select or fall back to one another. Native and
WASIX physical archives are family scoped; logical PostgreSQL dump/restore is
the bridge between them.
